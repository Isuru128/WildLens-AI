# WildLens-AI
Snap. Identify. Explore Nature.

An AI-powered React-Native mobile application that helps users identify wildlife and plant species by simply taking or uploading a photo. The application uses artificial intelligence to recognize the species and provides detailed biological information, conservation status, habitat, and interesting facts.

Designed primarily for **tourists, safari guides, wildlife photographers, researchers, and nature enthusiasts**, WildLens AI aims to make exploring nature more educational and interactive.

---

## 📱 Features

- 📷 Capture or upload wildlife photos
- 🤖 AI-powered species identification
- 📖 Detailed biological information
- 🌿 Identify animals, birds, reptiles, trees, and plants
- 📍 Habitat and distribution information
- ⭐ Confidence score for AI predictions
- 💾 Save identification history
- 🔍 Search previously identified species
- 🌐 Multi-language support *(Future)*
- 🔊 AI voice descriptions *(Future)*
- 🗺️ Wildlife location map *(Future)*
